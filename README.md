# ShopUG

A React + Vite + Tailwind CSS starter project for the ShopUG shopping website.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy
Push this folder to a GitHub repository and import it into Vercel.
Vercel build command: `npm run build`
Vercel output directory: `dist`

## Important
Checkout and sign-in in this starter are demo-only. No real payments or secure customer accounts are configured. Do not collect real customer payments or sensitive information until a trusted payment provider and secure backend have been integrated.
